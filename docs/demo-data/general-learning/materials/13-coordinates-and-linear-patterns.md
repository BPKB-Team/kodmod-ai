# Koordinat dan Pola Linear

Mata pelajaran: Matematika

Tingkat: Umum

Bahasa: Indonesia

## Tujuan belajar

- Membaca pasangan koordinat (x, y).
- Membuat tabel nilai dari sebuah aturan.
- Menjelaskan perubahan tetap dalam pola linear.

Titik pada bidang ditulis sebagai pasangan (x, y). Angka pertama menunjukkan posisi mendatar dan angka kedua posisi tegak. Mulailah dari titik asal (0, 0), bergerak mendatar sesuai x, lalu tegak sesuai y.

Sebuah aturan dapat menghubungkan masukan x dengan keluaran y. Contoh y = 2x + 1. Jika x bernilai 0, 1, 2, 3, 4, maka y bernilai 1, 3, 5, 7, 9. Setiap kenaikan satu pada x menaikkan y sebanyak dua. Tabel membantu memeriksa pola sebelum titik digambar.

Grafik yang membentuk garis lurus menunjukkan perubahan tetap dalam rentang yang diamati. Grafik membantu melihat hubungan, tetapi tidak selalu membuktikan aturan itu berlaku di luar data yang tersedia.

## Latihan
1. Pada titik (3, 5), tentukan x dan y.
2. Gunakan y = 2x + 1 untuk mencari y saat x = 4.
3. Lengkapi nilai y untuk x = 0, 1, 2, 3 dengan aturan y = 3x.
4. Jelaskan arti perubahan y yang tetap ketika x bertambah satu.
