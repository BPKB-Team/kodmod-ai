# Diagram dan presentasi arsitektur KODMOD

Berkas di direktori ini menjelaskan komponen aplikasi dan alur pembelajaran.
Diagram merupakan dokumentasi desain; diagram tidak membuktikan bahwa setiap
provider atau konfigurasi deployment telah diuji secara langsung.

## Presentasi

| Berkas | Cakupan |
|---|---|
| `KODMOD_System_Architecture_Deck_Detailed_Flow.pptx` | Sepuluh slide dengan rincian alur sistem. |
| `KODMOD_System_Architecture_Deck_Full_Agentic_Flow.pptx` | Sebelas slide yang menguraikan alur agen dan penyimpanan. |
| `KODMOD_System_Architecture_Deck_Final.pptx` | Ringkasan arsitektur tiga slide. |
| `KODMOD_System_Architecture_Deck_With_Logos.pptx` | Ringkasan tiga slide dengan logo komponen. |

## Diagram PNG

`KODMOD_Architecture_Full_System.png` merangkum sistem. Berkas dengan nama
`Agentic`, `Quiz`, `Scoring`, dan `Appendix` menjelaskan bagian alur tersebut.
Versi dengan akhiran `_Zoom` menyediakan gambar beresolusi lebih tinggi.
